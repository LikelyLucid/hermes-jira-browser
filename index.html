Built for the handoff

Keep the issue close to the work.

Use a focused board or list to find the next ticket, then carry its project and session context into the work that follows.

01

Find the next ticket

Switch between Board and List, save views for assigned issues, active sprints, or backlogs, and narrow the current view with quick filters.

02

Keep work attached

Map a Jira project to a Hermes Project and worktree. Resume a linked conversation or explicitly start another one in that worktree.

03

Carry context carefully

Inspect repository and pull-request context, or insert selected Jira comments and attachment metadata into a draft. Insertion never sends a message.

Credentials stay server-side

Jira credentials remain in the Python backend; settings and Desktop storage are credential-free. Jira descriptions and comments are treated as untrusted reference data. Read the security notes.

Add Jira to your Hermes workspace.

Install the unified plugin in your active Hermes home, then follow the setup guide to configure Jira and open the workspace.

Clone the plugin

export HERMES_HOME="${HERMES_HOME:-$HOME/.hermes}"
git clone https://github.com/LikelyLucid/hermes-jira-browser.git \
  "$HERMES_HOME/plugins/jira-browser"
Full installation and configuration guide ↗

Requires Hermes Agent, Hermes Desktop, Python 3.11+, Git, and Jira Cloud credentials.
